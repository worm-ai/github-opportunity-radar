# 模型降级研究的恢复核验

## 问题

证据优先降级模式可以按明确线索搜索 GitHub 并保存资料，但原有 `resume-evaluation` 只接受失败评估任务。模型恢复后，用户只能重新规划、搜索和采集，已完成的网络工作没有可用的恢复入口。

## 改动

`resume-evaluation` 现在也接受采集结束的降级任务。恢复先根据持久化的原始问题重新生成计划；旧降级计划、筛选理由和空评估只作为历史记录，不能成为新的语义事实。新的计划复用已保存候选、来源和搜索回执，只在新评估记录明确缺口且预算允许时补搜和采集。父任务快照不变，请求标识保持幂等。

如果模型仍不可用，恢复任务会保留 `partial`/失败状态并显示原因，不生成推荐。界面不再承诺“不会搜索或采集”，因为缺口恢复可能执行有界补搜。

## 验证

- 分析与服务测试：125 项通过，覆盖降级恢复、重新规划、材料复用、父任务不变和请求幂等。
- 全项目生产构建通过。Vite 仍报告既有的大包体积提示。
- `node scripts/verify-requirement-fallback-browser.mjs` 通过：Edge 桌面与 390px 手机无横向溢出，页面错误 0，写请求 0；实验状态读取失败时启动按钮保持禁用。
- `node scripts/verify-demand-recovery-http.mjs` 通过：启动隔离生产服务和本地模型 fixture，注入一条已完成降级采集的父任务，通过真实 HTTP `resume-evaluation` 重新规划并复用 1 份来源；子任务为 `partial`、无推荐，`replanned=true`，重复请求返回同一子任务（HTTP 200）。恢复不重复初始搜索；隔离数据保存在临时目录，未修改正式数据库。
- `node scripts/verify-demand-live-http.mjs` 通过：启动当前生产构建的隔离服务，使用本地 OpenCode 故障 fixture 触发证据降级，同时走真实 GitHub HTTPS 搜索与仓库资料采集。一次运行得到 1 次搜索、4 个真实候选仓库和 8 份来源，任务为 `partial`、无推荐；未启用 Codex 或自动付费回退。隔离数据库位于临时目录，未修改正式数据库。
- 当前生产构建已另起 `127.0.0.1:4341`，使用 `.data/live-20261026-v6`，不触碰原 4340。该入口的 features 接口已返回 `fallbackEvaluationResume:true`；Edge 手机视口打开 `/research` 通过，页面错误 0、无横向溢出。
- 结果页新增候选摘要后，Web 类型检查、27 项相关 Web 测试和生产构建通过（Vite 仅保留既有的大包体积提示）；4341 已重载新资源，Edge 手机视口再次通过，页面错误 0、无横向溢出。
- 为让真实结果可直接审阅，4342 以只读复用此前临时真实 GitHub 研究数据库启动，页面显示 4 个已采候选、8 份来源、“尚未完成语义筛选”提示和“用已采材料继续比较”按钮；Edge 桌面页面错误 0。此前尝试把数据库复制进 4341 的操作被自动审批以 `blocked by policy` 拒绝，命令未执行，因此没有修改 4341 或正式数据。
- 随后通过 `scripts/create-demand-demo.mjs` 使用存储层导入同一核验快照到项目内 `.data/demand-demo-20261026`，启动 4343 持久化演示入口。API 确认任务为 `partial`、4 个项目、8 份来源；Edge 桌面页面确认候选、恢复按钮可见且页面错误 0。该导入未重新调用模型或网络。
- 同一导入脚本支持指定来源数据库和任务快照，已将 4340 中真实社会模拟研究 `f6c68b08-19e8-41ee-8443-c3c8119c4413` 导入 `.data/demand-social-demo-20261026` 并启动 4344。该入口保留 8 个候选、15 份来源、Microverse/Agent-Farm 等静态比较和“不推荐直接采用”的结论；Edge 页面确认玩家介入、重启等验收条件文字和候选可见，页面错误 0。
- 在独立 4345 服务显式选择本机 Codex `gpt-6.1-sol` 后，真实社会模拟需求完成 4 次初始搜索、2 次缺口补搜、8 个候选、两轮评估和反方审查。首次评估超时，`resume-evaluation` 未重复初始搜索而复用材料并完成后续评估；最终任务 `partial`、无推荐，反方明确要求先固定版本并实测持久状态、事件调度和重启恢复。Codex 费用取决于本机配置，不属于免费 OpenCode 验证。

## 边界

这证明了恢复机制和证据谱系，不证明模型一定可用、候选能运行或组合接口兼容。当前 4340 服务的前端静态资源可加载新构建；后端重启此前被自动审批以 `blocked by policy` 拒绝，因此磁盘上的后端恢复改动尚未被现有进程加载。
