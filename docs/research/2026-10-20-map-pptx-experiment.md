# 从模型否决走到真实接口实验

日期：2026-10-20。产品锚点：[PRD](../PRD.md)。本次验证 Map Design 与 GenOffice 的文件交接，不改变此前模型淘汰记录，不将技术可行性当作需求或商业价值。

## 实际结论

固定版本能够完成“地区 CSV → 地图 PNG → PPTX → 重复替换图片”，本机 PowerPoint 14.0 正常打开三个产物。原始地图的 51 个州及特区匹配正确；同一输入的 SVG 内容一致；模拟更新确实进入当前 PPTX 图片引用。两次相同更新保留 1 页、1 张图和相同位置，同版本 PowerPoint 导出的图像无像素差异。

这支持狭义文件接口假设。尚未测量相对于用户现有工作方式的时间节省、纠错成本或重复任务频率；未进行访谈、试用或付费验证，不能宣称发现了商机。GenOffice 使用的是源码引擎及操作层，未验证其打包 CLI 或桌面应用。

## 对抗式检查

| 输入或检查 | 观测 | 对集成的含义 |
| --- | --- | --- |
| 原始 CSV | 51 个地区，California=-0.31%，无警告或未匹配 | 该输入的匹配成立 |
| 相同 CSV 重跑 | SVG SHA-256 一致 | 本次相同输入的内容稳定 |
| 模拟更新 | California=10.00%，PNG 字节变化，PPTX 当前图片指向新 PNG | 不是只在压缩包中存入未使用图片 |
| 未知 FIPS 99 | `render` 退出 0，报告有 1 个未匹配行 | 退出成功不等于数据完整 |
| 重复 California | `render` 退出 0，警告并保留第一条 | 必须让用户看到重复键，不能悄悄采用新值 |
| 缺失 California 数值 | `render` 退出 0，警告并留空，图上有值地区变为 50 | 缺失没有变成零，仍需确认是否允许导出 |
| PPTX 重复替换 | 当前图片字节哈希正确，1 页、1 张图、位置不变；输入哈希写入备注 | 该文件操作可重复执行，不是跨格式通用幂等证明 |
| PowerPoint 打开与渲染 | 原始/更新有 18,391 个像素变化；同一更新的两次渲染为 0 差异 | 证明本机版本的可显示性，不证明全部 Office 版本兼容 |

原始 Map Design 已提供异常诊断，不能把“调用方忽略警告”描述成上游没有检测。这个发现提示适配器必须消费报告；它本身还不足以支持一项独立商业产品。

地图作为完整栅格图片进入 PPTX，地区和文字不可单独编辑。若真实用户要求逐个地区编辑、复杂模板替换、多语言排版或可访问性，当前实验没有证明满足这些需求。原始结果 JSON 在生成时仍列出“尚未做 PowerPoint 渲染”；后续独立渲染证据由单独的 `powerpoint-verification.json` 记录，不改写前一阶段历史。
