# 研究结果关联人工实测

2026-10-23，隔离实例 `http://127.0.0.1:4318`。

从第一性原理出发，研究的交付是帮助用户决定采用哪个实现、补什么、先验证什么。已有行为实验若只存在于独立页面，用户仍需自行发现并核对证据。本轮将归档关联到研究结果前部，同时保留人工实验与历史模型判断之间的边界。

## 已实现

- 按仓库名称及 GitHub 地址共同关联，项目 ID 不能单独成为依据；多组件实验保留未匹配组件提示。
- 只用实际已读代码的完整提交 SHA 比较版本，区分相同、不同、混杂/不全、未知；README 和 blob 哈希不能用于推断提交。
- 显示验证问题、结论、反证、执行输入/环境、限制与下一步，并跳转到具体实测记录及产物。
- 单独导出研究与补充实测 JSON，保留原始导出及历史推荐。导出记录提取时间和归档警告，未内嵌产物。
- 读取失败不能解释为没有实验；缺损归档警告可见。关联、浏览与导出不调用模型，不修改任务或上游代码。

## 对抗式审查与下一步

同仓库仅表示有值得查看的证据，同提交仅表示版本对应。人工实验的具体问题可能不适用于当前需求，原模型也没有自动读入这些新增实测；本功能不自动改变推荐或宣称完整游戏可用。导出为当时快照，不能保证未来归档仍可下载。全局归档读取有数量上限，因此“当前可读归档没有匹配”不能解释为从未有人测试过。

本轮消除了已有证据与选型界面的断点，属于可核查进展，但不能证明独立用户节省时间。下一项实质决策仍是比较 agent-world 的单项目改造成本和替代实现，优先处理可靠持久化及状态进入自主决策的闭环，而非继续堆叠报告或强行组合两个世界状态系统。
