## 实际产品障碍与修复

Actual 初次收录只有 #5191、#7669、#5949、#9282 四条自动样本。原有核查入口拒绝 #4616，返回 `unknown_origin_issue`；重要的长期任务不能因不在最近五条开放样本中就被排除。

新增项目档案“补充其他问题讨论”：输入正整数、`#编号` 或同仓库 GitHub Issue 地址，经 iii `collect-evidence` 和现有 W2A 事件采集正文、有界评论及当前状态，支持开放与关闭讨论。地址只用于提取编号，客户端按已知公开仓库调用官方 API，不请求任意输入地址；跨仓库、PR 地址和其他协议拒绝。

显式选择存于现有讨论快照 JSON，schema 仍为 10；不修改自动样本。项目档案和研究材料按编号去重合并，目录的三条问题摘要优先选择按需材料。每项目最近十份核查的上限在页面可见，超额旧选择退出当前材料，已保存判断的引用快照仍保留。

对抗检查发现另一个边界：自动扫描看到较新问题后，旧核查必须持续失效，即使该问题随后离开最近样本。现将较新样本的更新时间写入讨论水位，重查达到水位后才恢复，避免过时评论重新进入分析。此路径有持久化重开验证。
