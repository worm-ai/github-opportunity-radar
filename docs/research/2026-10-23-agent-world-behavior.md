# 社会模拟候选：从源码判断走到行为对照

本轮结论：agent-world 可作为共享世界与动作接口的改造候选，尚不支持将其推荐为满足原需求的完整社会模拟游戏。暂缓组合 Microverse；优先估算一个项目补齐决策、持久化和玩家闭环的成本。没有修改上游实现。

## 问题与范围

用户希望多个角色有身份、记忆和目标，能自主交流、形成关系并对共同事件行动，玩家可以观察和介入。最低判断依据应是“输入改变后，相关状态与动作是否变化，退出后是否恢复”，项目介绍或关系数值存在都不足以回答。

固定 [sbenodiz/agent-world 提交](https://github.com/sbenodiz/agent-world/tree/13d62dbdeeca07c7b5bb3b8aa264ca9834b01882)，36 份原版源码/地图/许可证/配置逐个核验 Git blob。运行 Python 3.12.10、Django 4.2.26、asgiref 3.11.0、sqlparse 0.5.3、tzdata 2025.2、numpy 2.2.6；wheel 核对 PyPI SHA-256。Django 与上游声明的 4.2 范围一致，SQLite 使用文件数据库和默认连接寿命 0，与上游 base 配置一致。仅配置必要应用与独立数据库，未加载完整服务器配置。

运行未改动的 WorldEngine、AgentRegistry、NPCManager、关系/事件/地图实现以及原版 migrations。各持久化阶段在独立子进程中载入；20 个随机种子 × 两种初始关系 × 三种事件，共 120 个 NPC 条件。动作由真实 handle_action 执行；没有以自造决策函数或模拟数据库代替上游。

## 观察与对抗复核

| 检查 | 实际观察 | 对选型的含义 |
| --- | --- | --- |
| 发言更新双方关系 | 内存为 +2/+2；未等定期刷新直接新进程载入为 +2/0 | 单次成功动作只保存行为者，接收者存在丢失窗口 |
| 记忆、位置保存正对照 | remember 和逐个 save_agent 后，新进程能恢复记忆、位置、关系 | 不能概括为整个项目无法持久化 |
| 批量保存 | save_all 报 Cannot operate on a closed database；接收者新增关系未恢复 | 默认连接配置下存在真实保存缺陷；不是仅凭静态代码猜测 |
| 世界时钟恢复 | 12 个 tick 后为第 1 天 09:00，新进程回到第 1 天 06:00 | 角色档案恢复不等于整个世界继续运行 |
| 世界事件投递 | 第 12 tick，双方收到 world_event，WorldLog 有一条记录 | 事件分发确实运行，不能称为没有世界事件 |
| 关系影响 NPC 行动 | -80 与 +80，60 对条件的动作、位置均无差异 | 已测脚本策略未随关系改变；不是证明外部 LLM 永远不能利用关系 |
| 世界事件影响 NPC 行动 | 无事件与世界事件，40 对条件均无差异 | 分发文本未连成已测 NPC 行动反馈 |
| 消息事件正对照 | 无事件与消息，40 对中 36 对行为不同 | 事件响应实验能观察到变化，不能把全部无差异归咎于实验不敏感 |

源码解释：`world/agents.py` 的 save_all 在 transaction.atomic 内逐个 save_agent，后者调用 close_old_connections；连接寿命 0 时关闭事务中的连接，错误被内部捕获。runworld 退出使用同一 save_all 原语，但本实验未执行完整管理命令和 OS 信号，因此不宣称完成真实服务器关停复现。逐个保存是诊断正对照，不是已向上游交付修复。

`world/npcs.py` 的已读内置策略按固定人格参数、到场/消息和随机数动作，未读取关系或记忆；跳过 world_event 等事件。外部代理可以通过接口取得上下文后自行决策，这需要另行实现和验证，不等于项目自带完整角色认知循环。

## 对产品演化的影响

此次研究避免了两种误判：有关系字段不等于关系驱动行为；有存档函数不等于恢复闭环成立。正确输出应是具体改造候选、已复现缺陷和下一步验收，而不是继续罗列相似仓库。

暂不组合两套世界/角色状态系统。下一步先给出单项目最小原型的工作边界：统一状态、可持续目标、读记忆/关系/事件的决策策略、可靠保存与恢复、观察及干预入口；与 Microverse 单项目改造比较成本后再选择。没有在本轮替用户实现完整游戏，也没有证明用户省时或市场需求。

实验原始阶段输出、失败日志、逐条件结果、依赖与源文件清单位于 `.data/experiments/agent-world-behavior`。完整成功运行由 `latest.json` 指向；初次保存预期失败保留。已归档至隔离实例“技术实测”，不改写原需求报告、失败续研或模型推荐。模型未执行这些行为实验，结果由助手本地运行后记录。

边界：合成角色而非真实用户任务；同步调用 NPCManager.tick，未验证异步服务器调度；未启动 Web/MCP 或外部 LLM；固定种子对照不是覆盖率统计。Microverse 仍仅有静态补证，不能据此断言另一个候选更优。
